Programação Paralela

Atividades práticas, lições e relatórios • Prof. Samuel Xavier de Souza
C / C99 OpenMP MPI CUDA / GPU cache & NUMA Amdahl / Gustafson

A disciplina DCA3703 estuda como medir, analisar e acelerar código numérico: hierarquia de memória, leis de escalabilidade, programação com threads e, por fim, memória distribuída e GPU. Cada tarefa reúne a parte teórica, a análise do código C e a medição executada no cluster NPAD/UFRN.
