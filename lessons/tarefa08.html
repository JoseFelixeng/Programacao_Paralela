Tarefa 08

Computação paralela em GPU

Introdução aos paradigmas de computação paralela em GPUs (CUDA, OpenCL) e seus padrões de acesso à memória. Foco em simulação de fluidos e circuitos elétricos em ambiente paralelo.

Contexto

GPUs são aceleradores especializados para computação paralela massiva. Frameworks como CUDA e OpenCL permitem escrever código paralelo em dispositivos gráficos. A memória global da GPU é compartilhada entre threads, mas com restrições de coerência.

Teoria

Principios de computação paralela em GPU:

  • Threads de GPU: Milhões de threads organizadas em blocos (CTA) e warps.
  • Memória global: Compartilhada, mas com coerência de cache.
  • Coalescência: Agrupamento de acessos de memória para maximizar throughput.
  • SIMT: Single Instruction, Multiple Threads - todas as threads executam a mesma instrução.

Prática

Implementou-se kernels CUDA para simulação de fluidos (método das linhas) e circuitos elétricos em GPU. Mediu-se o desempenho comparando CPU vs GPU.

Experimentos mostraram ganhos significativos em simulações paralelas, mas com overhead de transferência de dados.

Resultados e análise

Os resultados indicam que:

  • GPUs oferecem ganhos de 10-100x sobre CPU para simulações paralelas.
  • Coalescência de memória é crítica para desempenho.
  • Transferência de dados entre CPU e GPU é um gargalo importante.

Referência Rápida

  • CUDA: Framework para programação de GPUs (NVIDIA).
  • OpenCL: Padrão aberto para computação paralela.
  • SIMT: Modelo de execução onde todas as threads executam a mesma instrução.
  • Coalescência: Agrupamento de acessos de memória para maximizar throughput.
  • Memória global: Compartilhada entre threads da GPU.

Conclusão

Esta tarefa introduziu os conceitos de computação paralela em GPU. A coalescência de memória e o modelo SIMT são fundamentais para obter ganhos significativos.
