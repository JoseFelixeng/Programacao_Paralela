Tarefa 02

Multiplicação matriz-vetor e cache

Multiplicação matriz-vetor e análise de impacto da hierarquia de memória (cache L1/L2/L3) no desempenho.

Contexto

Este trabalho foca na multiplicação matriz-vetor, uma operação central em algoritmos de processamento de imagens e simulações científicas. A hierarquia de memória desempenha um papel crucial no desempenho, pois a localidade espacial e temporal afeta diretamente a frequência de cache misses.

Teoria

O produto matriz-vetor é calculado como C[i][j] = Σ A[i][k] * B[k][j]. A complexidade é O(n³) para matrizes n×n. A hierarquia de memória influencia o desempenho através de:

  • Localidade espacial: Acesso contíguo à memória melhora a previsibilidade de cache.
  • Localidade temporal: Reutilização de dados recentemente carregados.
  • Cache L1/L2/L3: L1 é mais rápido e menor, L2 intermediário, L3 compartilhado.

Prática

Implementou-se a multiplicação matriz-vetor em C/C++ com otimizações de cache (loop tiling, loop interchange). Mediu-se o desempenho em diferentes níveis de hierarquia de memória simulada.

Experimentos com matrizes de tamanhos variados (100×100 até 500×500) mostraram que o cache L1 reduz a latência média, enquanto o L3 oferece ganhos moderados.

Resultados e análise

Os resultados indicam que:

  • O cache L1 reduz drasticamente a latência de acesso para dados frequentemente reutilizados.
  • O loop tiling melhora o desempenho ao maximizar a localidade espacial.
  • O paralelismo de threads oferece ganhos moderados devido à sobrecarga de sincronização.

Referência Rápida

  • Loop Tiling: Reorganiza os loops para maximizar a localidade espacial.
  • Loop Interchange: Troca a ordem dos loops para melhorar a localidade temporal.
  • Cache L1: Mais rápido, menor capacidade, ideal para dados quentes.
  • Cache L3: Maior capacidade, compartilhado entre núcleos.
  • Complexidade: O(n³) para multiplicação matriz-vetor.

Conclusão

Esta tarefa demonstrou como a hierarquia de memória afeta o desempenho de algoritmos de multiplicação matriz-vetor. Otimizações de cache e reorganização de loops são essenciais para alcançar o piso de desempenho em processadores modernos.
