Tarefas 16 e 17: Multiplicação de Matrizes

Teoria

  • Multiplicação (MatMul): A operação básica de computação científica. Otimizar MatMul é sobre tiling/blocking para maximizar a reutilização de dados na cache.
  • Complexidade: O algoritmo ingênuo é O(n³). Com tiling, reduzimos drasticamente os *cache misses*.

Referência Rápida

  • Tiling: Quebrar matrizes em blocos que cabem na L1/L2.
  • Loop Reordering: Mudar a ordem (i, k, j) para acessar a memória contiguamente.
