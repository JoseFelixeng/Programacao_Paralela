Tarefa 18: VADD (Vetor Addition)

Teoria

  • VADD: Soma de dois vetores (C = A + B). É o problema clássico de memória intensiva.
  • GPU/Heterogêneo: Introdução ao conceito de computação paralela massiva vs. CPU.

Referência Rápida

  • Vetorização: Capacidade da CPU/GPU de processar múltiplos elementos simultaneamente (SIMD).
  • Throughput: Vazão de dados, vital para problemas de largura de banda.
