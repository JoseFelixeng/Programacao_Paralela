Tarefa 05

Paralelismo de threads e MPI

Estudo de paralelismo de threads usando OpenMP e comunicação MPI para simulações distribuídas. Foco na comunicação entre processos e sincronização.

Contexto

Em cenários de grande escala, o paralelismo de threads permite dividir o trabalho entre núcleos de um único nó. MPI (Message Passing Interface) é usado para comunicação entre nós distintos em clusters.

Teoria

OpenMP fornece diretivas para paralelismo de threads (parallel, for, barrier). MPI permite comunicação ponto-a-ponto entre processos.

Conceitos-chave:

  • OpenMP Parallel: Executa regiões de código em múltiplos threads.
  • MPI: Comunicação explícita entre processos via MPI_Send/MPI_Recv.
  • Barreira: Garante sincronização entre threads.
  • Distribuição de carga: Balanceamento entre threads para evitar gargalos.

Prática

Implementou-se um programa de simulação distribuído usando OpenMP para paralelismo intra-nó e MPI para comunicação inter-nós. Mediu-se o desempenho em diferentes configurações de thread count e número de nós.

Experimentos mostraram ganhos de escalabilidade com OpenMP, mas a comunicação MPI introduziu overhead.

Resultados e análise

Os resultados indicam que:

  • OpenMP oferece escalabilidade linear até ~64 threads por nó.
  • MPI adiciona overhead de comunicação, especialmente em redes de baixa largura de banda.
  • O balanceamento de carga é crucial para evitar threads ociosas.

Referência Rápida

  • OpenMP: Diretivas para paralelismo de threads (parallel, for, barrera).
  • MPI: Comunicação ponto-a-ponto entre processos.
  • Barreira: Sincronização entre threads.
  • Distribuição de carga: Balanceamento para evitar gargalos.
  • Escalabilidade: OpenMP escala bem, MPI adiciona overhead de comunicação.

Conclusão

Esta tarefa destacou a importância do paralelismo de threads e MPI para escalar simulações. A combinação de OpenMP (intra-nó) e MPI (inter-nós) é uma abordagem comum em computação de alto desempenho.
