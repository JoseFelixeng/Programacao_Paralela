Introdução

Este portal reúne o material produzido ao longo das atividades de Programação Paralela. Cada tarefa pode conter uma aula complementar, relatório, código-fonte, scripts e resultados experimentais.

As aulas ficam em docs/lessons/. Os arquivos originais e resultados das atividades ficam nas respectivas pastas Tarefa_* do repositório.
